A Missão:
Você receberá um número inteiro positivo num. Sua tarefa é contar quantos passos são necessários para reduzi-lo a zero, 
seguindo estas duas regras a cada passo:

Se o número atual for par, você deve dividi-lo por 2.

Se o número for ímpar, você deve subtrair 1 dele.

Dica: Você precisará de uma variável (como passos) começando em zero para ir contando cada vez que uma ação for feita.

Exemplo:

Entrada: num = 14

Saída: 6

Acompanhe a lógica (Passo a Passo):

Passo 1: 14 é par; divida por 2 = 7.

Passo 2: 7 é ímpar; subtraia 1 = 6.

Passo 3: 6 é par; divida por 2 = 3.

Passo 4: 3 é ímpar; subtraia 1 = 2.

Passo 5: 2 é par; divida por 2 = 1.

Passo 6: 1 é ímpar; subtraia 1 = 0.

Total: 6 ações.
